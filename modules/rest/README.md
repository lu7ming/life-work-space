## 性能优化

### ✅ Canvas 2D渲染
- 禁用alpha通道（{ alpha: false }）
- 设备像素比限制最大2x（防止Retina屏性能问题）

### ✅ 对象池
- 星星、大雪花、中小雪花全部预分配
- 出界重置复用，避免GC抖动

### ✅ 离屏Canvas预渲染
- 7种大雪花造型预渲染到离屏Canvas
- 运行时仅drawImage，无实时路径计算

### ✅ 动画优化
- 仅使用transform + opacity
- 零layout回流
- requestAnimationFrame驱动
- dt限制最大0.1s（防卡顿跳帧）

### ✅ 支持 prefers-reduced-motion
- 检测系统减弱动画偏好
- 减弱模式下显示40朵静态雪花
- 无飘落动画

### ✅ 资源释放
- 离开时立即cancelAnimationFrame
- 移除resize监听器
- 恢复UI元素可见性

**目标：iPad上稳定60fps ✅**
